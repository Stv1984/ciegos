Modo acompañante

Esta pantalla es para una persona que ve. Sirve para dar permisos, corregir nombres de paradas y ajustar opciones. Se cierra sola después de un minuto sin usarla.

1. Permisos (hacerlo una sola vez)

El navegador pide permiso para la ubicación y el micrófono con ventanas que una persona ciega no puede aceptar sola. Tocá el botón y aceptá cada ventana. Después la aplicación los recuerda.

2. Guardar una parada con el teclado

Pararse en la esquina y escribir un nombre. Se guarda la ubicación actual del GPS.
